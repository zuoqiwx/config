# ~/.config

Personal macOS configuration, tracked as a git repository rooted at `~/.config`.

- Repository: <https://github.com/zuoqiwx/config>
- Target path: `~/.config`
- Platform: macOS (Intel, Homebrew prefix `/usr/local`)

## Repository layout

| Path | Tool | What it configures |
| --- | --- | --- |
| `btop/btop.conf` | [btop](https://github.com/aristocratos/btop) | Resource monitor, tokyo-night theme |
| `gh-dash/config.yml` | [gh-dash](https://github.com/dlvhdr/gh-dash) | `gh dash` PR/issue/notification sections |
| `ghostty/config` | [Ghostty](https://ghostty.org) | Terminal emulator |
| `herdr/config.toml` | herdr | Terminal workspace manager for AI coding agents |
| `htop/htoprc` | [htop](https://htop.dev) | Process viewer |
| `nvim/` | [Neovim](https://neovim.io) | Editor: `init.lua`, `lua/`, `lsp/`, `after/`, `stylua.toml`, `nvim-pack-lock.json` |
| `opencode/opencode.jsonc` | [opencode](https://opencode.ai) | Main config |
| `opencode/tui.jsonc` | opencode | TUI keybinds |
| `starship.toml` | [Starship](https://starship.rs) | Shell prompt |
| `tmux/tmux.conf` | [tmux](https://github.com/tmux/tmux) | Terminal multiplexer + plugin options |
| `tmux/scripts/` | tmux | Status-bar helper scripts (CPU temp, spacer) |
| `Brewfile` | Homebrew | CLI tools and casks needed by the configs |

## Tools and dependencies

### Ghostty

- Install: `brew install --cask ghostty`
- Config: `ghostty/config`
- Depends on the JetBrainsMono Nerd Font (`font-jetbrains-mono-nerd-font` cask) for glyphs.
- Uses the tokyo-night theme, copied clipboard-on-select, and macOS option-as-alt.

### tmux

- Install: `brew install tmux`
- Config: `tmux/tmux.conf`; helper scripts in `tmux/scripts/`
- Plugins are **not tracked** (`tmux/plugins/` is gitignored) and are installed by
  [TPM](https://github.com/tmux-plugins/tpm):
  - `tmux-plugins/tpm`
  - `tmux-plugins/tmux-sensible`
  - `janoamaral/tokyo-night-tmux`
  - `tmux-plugins/tmux-cpu`
- Extra dependency: `osx-cpu-temp` (`brew install osx-cpu-temp`) for the CPU-temperature
  status widget. `tmux/scripts/cpu-temp.sh` exits silently when it is missing.
- `tmux.conf` also defines native vim-tmux-navigator bindings; the matching Neovim
  plugin `vim-tmux-navigator` is in `nvim-pack-lock.json`.

### Neovim

- Install: `brew install neovim` (config targets Neovim 0.12+)
- Config: `nvim/`
- Plugins are managed by the built-in `vim.pack` (Lua 0.12+ API). `nvim/init.lua`
  declares them, `nvim-pack-lock.json` pins revisions, and missing plugins are
  installed automatically from their git sources on the next launch.
- Required binaries:
  - `git` (plugin installs)
  - `tree-sitter` + a C toolchain (`cc`, `make`) for parser builds
  - `fzf` (fzf-lua picker)
  - `ripgrep` (`:live_grep` / grepping)
  - `bat` (file preview headers)
- Language servers, configured natively in `nvim/lsp/*.lua`:
  - Lua: `lua-language-server` (`brew install lua-language-server`)
  - Go: `gopls` (`go install golang.org/x/tools/gopls@latest`)
  - TypeScript/JavaScript: `vtsls` (`npm i -g @vtsls/language-server`)
- Formatters, wired through `conform.nvim` (`nvim/lua/plugins/format.lua`):
  - Lua: `stylua` (`brew install stylua`)
  - JS/TS/CSS/HTML/JSON/YAML/Markdown/GraphQL: `prettier` (`npm i -g prettier`)
  - Go: `gofmt` (ships with Go)
- Bottom terminal: `Ctrl+/` (or `Ctrl-_`) focuses/hides a persistent shell split,
  keyed per project root; `<leader>ft` / `<leader>fT` open root/cwd terminals.
  Provided by `snacks.nvim` (pure Lua, lazy-loaded on first use — no extra binaries).
- Update plugins with `:lua vim.pack.update()` (review the buffer, `:write` to apply).

### btop

- Install: `brew install btop`
- Config: `btop/btop.conf`
- `color_theme` points at a **versioned Homebrew Cellar path**. After a Homebrew
  upgrade the path no longer exists; either update the line or copy the theme to
  `~/.config/btop/themes/` and set `color_theme = "tokyo-night"`.

### htop

- Install: `brew install htop`
- Config: `htop/htoprc`
- htop rewrites this file when settings change in the UI, so expect churn after
  interactive use.

### Starship

- Install: `brew install starship`
- Config: `starship.toml`
- Requires a one-time shell hook in `~/.zshrc` (not tracked here):
  `eval "$(starship init zsh)"`.
- The prompt uses Nerd Font glyphs; install the JetBrainsMono Nerd Font.

### gh-dash

- Install: `gh extension install dlvhdr/gh-dash`
- Config: `gh-dash/config.yml`
- Requires the GitHub CLI (`brew install gh`) authenticated via `gh auth login`.
- Credentials are stored by `gh` outside this repo.

### opencode

- Install: `curl -fsSL https://opencode.ai/install | bash`
  (or `brew install anomalyco/tap/opencode`)
- Config: `opencode/opencode.jsonc` and `opencode/tui.jsonc`
- The install script places the binary in `~/.opencode/bin`; add it to `PATH` in
  `~/.zshrc`.
- `opencode/.opencode/` (plugin dependencies, lockfile, generated package.json) is
  gitignored and regenerated by opencode; `opencode/.gitignore` also ignores
  `package.json`/lockfiles deliberately.
- Provider credentials live in `~/.local/share/opencode/auth.json` and are never
  committed.

### herdr

- Install: `brew install herdr`
- Config: `herdr/config.toml`
- Runtime state (`session.json`, `*.log`, `.plugins.lock`) is gitignored.
- Update with `herdr update`.
- Intel macOS limitation: this machine is a Homebrew Tier 3 configuration (x86 on
  recent macOS), and no bottles exist for `herdr`, `zig`, or `llvm@22`. Upgrading
  would source-build LLVM, Zig, and Rust for hours, so the formula is pinned here
  (`brew pin herdr`) and stays at the installed version; `brew bundle check` treats
  the pin as satisfied. On Apple Silicon, or once bottles exist, use
  `brew unpin herdr && brew upgrade herdr`.

## Fresh machine onboarding

Assumes a clean macOS machine with Homebrew and `git` available.

1. **Clone the repo into `~/.config`**

   ```sh
   git clone https://github.com/zuoqiwx/config.git ~/.config
   ```

   If `~/.config` already exists with content, move it aside first or clone to a
   temp directory and copy the files in; the clone will refuse a non-empty target.

2. **Install CLI tools and casks**

   ```sh
   brew bundle --file ~/.config/Brewfile
   ```

   This covers `btop`, `fzf`, `fnm`, `gh`, `git`, `go`, `herdr`, `htop`,
   `lua-language-server`, `neovim`, `osx-cpu-temp`, `ripgrep`, `bat`, `starship`,
   `stylua`, `tmux`, `tree-sitter`, plus the Ghostty and Nerd Font casks.

3. **Add the shell hooks** to `~/.zshrc` (this file is intentionally not tracked):

   ```sh
   eval "$(fnm env --use-on-cd --shell zsh)"
   eval "$(starship init zsh)"
   export PATH="$HOME/.opencode/bin:$PATH"
   ```

4. **Install opencode**

   ```sh
   curl -fsSL https://opencode.ai/install | bash
   ```

5. **Install Node/Go global tooling**

   ```sh
   npm i -g prettier @vtsls/language-server
   go install golang.org/x/tools/gopls@latest
   ```

6. **Install tmux plugins (TPM)**

   ```sh
   mkdir -p ~/.config/tmux/plugins
   git clone https://github.com/tmux-plugins/tpm ~/.config/tmux/plugins/tpm
   ```

   Then start `tmux` and press `prefix + I` (`Ctrl-b` then `I`) to install the
   remaining plugins. `tmux/plugins/` stays gitignored.

7. **Install Neovim plugins**

   Launch `nvim` once. `vim.pack.add()` installs anything missing at the revisions
   in `nvim-pack-lock.json`. Confirm with `:checkhealth`.

8. **Authenticate GitHub CLI and add gh-dash**

   ```sh
   gh auth login
   gh extension install dlvhdr/gh-dash
   ```

9. **Verify**

   | Check | Command |
   | --- | --- |
   | Prompt renders | `starship --version`, restart shell |
   | tmux loads | `tmux new -s verify` then `prefix + I` once more if needed |
   | tmux temp widget | `~/.config/tmux/scripts/cpu-temp.sh` prints a temperature |
   | Neovim health | `nvim +checkhealth` |
   | Tree-sitter parsers | `:TSInstall` info / open a Lua or Go file |
   | Go LSP | open a `.go` file inside a module (`gopls` on `PATH`) |
   | TS LSP | open a `.ts` file (`vtsls` on `PATH`) |
   | gh-dash | `gh dash` |
   | opencode | `opencode --version` |
   | herdr | `herdr status` |
   | btop theme | `btop`, then check the theme loads |
   | htop config | `htop` |

## Intentionally untracked

- `tmux/plugins/` — tool-managed, reinstalled by TPM.
- `node_modules/` everywhere, including `opencode/.opencode/`.
- `herdr/*.log`, `herdr/session.json`, `herdr/.plugins.lock` — runtime state.
- `configstore/`, `iterm2/`, `mole/` — outside the tracked tool set. This includes
  `iterm2/sockets/secrets`.
- Shell rc files (`~/.zshrc`) and everything outside `~/.config`.
- Credentials: `~/.local/share/opencode/auth.json`, `gh` auth, SSH keys.

## Caveats

- `ripgrep`, `bat`, and `gopls` are declared dependencies; if Neovim grep/preview or
  the Go LSP misbehaves, check they are installed and on `PATH`.
- `btop/btop.conf` contains an absolute, versioned Homebrew path (see btop above).
- `htoprc` is rewritten by htop and will show diffs after tuning settings in the UI.
- `starship` and opencode require `~/.zshrc` changes that are not part of this repo.
- `herdr` is pinned (`brew pin herdr`) on x86 macOS: Tier 3 means no bottles, so an
  upgrade triggers a multi-hour LLVM/Zig/Rust source build. Apple Silicon machines
  do not need the pin.
- No symlink farm is used: this repo covers `~/.config` only. Files elsewhere in
  `$HOME` are not tracked; see Stow / `yadm` / a bare repo if that changes.
